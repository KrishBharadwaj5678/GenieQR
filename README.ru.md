<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/icon/icon.png" width="30"/> GenieQR</h1>

<p align="center">
  GenieQR позволяет быстро преобразовывать текст, URL-адреса и другие данные в высококачественные QR-коды, делая обмен информацией быстрее, проще и доступнее.
</p>

## <img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность           | Описание                                       |
| --------------------- | ---------------------------------------------- |
| 🧩 Генерация QR-кодов | Мгновенное создание QR-кодов из текста или URL |
| ⚡ Быстро и просто     | Быстрый и удобный интерфейс                    |
| 🎨 Чистый интерфейс   | Минималистичный дизайн на основе Streamlit     |
| 📥 Скачивание         | Возможность сохранять созданные QR-коды        |
| 🌐 Веб-приложение     | Работает непосредственно в браузере            |

## <img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/GenieQR.git
```

### 2️⃣ Переход в директорию проекта

```bash
cd GenieQR
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
streamlit run app.py
```
