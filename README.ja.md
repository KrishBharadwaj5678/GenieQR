<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/icon/icon.png" width="30"/> GenieQR</h1>

<p align="center">
  GenieQRは、テキスト、URL、その他のデータを高品質なQRコードにすばやく変換できるツールです。情報の共有をより速く、簡単かつ便利にします。
</p>

## <img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能          | 説明                        |
| ----------- | ------------------------- |
| 🧩 QRコード生成  | テキストやURLからQRコードを瞬時に生成できます |
| ⚡ 高速・シンプル   | 素早く簡単に使用できるインターフェース       |
| 🎨 シンプルなUI  | Streamlitを使用したミニマルなデザイン   |
| 📥 ダウンロード機能 | 生成したQRコードを保存できます          |
| 🌐 Webベース   | ブラウザから直接実行できます            |

## <img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash id="4iqyju"
git clone https://github.com/KrishBharadwaj5678/GenieQR.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash id="q3yqg7"
cd GenieQR
```

### 3️⃣ 依存関係をインストール

```bash id="3z0f3c"
pip install -r requirements.txt
```

### 4️⃣ アプリを起動

```bash id="n1h3k6"
streamlit run app.py
```
