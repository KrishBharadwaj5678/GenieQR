<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/icon/icon.png" width="30"/> GenieQR</h1>

<p align="center">
  O GenieQR permite transformar rapidamente textos, URLs e outros dados em QR Codes de alta qualidade, tornando o compartilhamento de informações mais rápido, simples e acessível.
</p>

## <img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso                | Descrição                                                 |
| ---------------------- | --------------------------------------------------------- |
| 🧩 Geração de QR Codes | Gere QR Codes instantaneamente a partir de textos ou URLs |
| ⚡ Rápido e Simples     | Interface rápida e fácil de usar                          |
| 🎨 Interface Limpa     | Design minimalista desenvolvido com Streamlit             |
| 📥 Opção de Download   | Salve os QR Codes gerados                                 |
| 🌐 Baseado na Web      | Execute diretamente no seu navegador                      |

## <img src="https://github.com/KrishBharadwaj5678/GenieQR/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/GenieQR.git
```

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd GenieQR
```

### 3️⃣ Instalar as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar o Aplicativo

```bash
streamlit run app.py
```
